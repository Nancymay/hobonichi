# Хобоничи 2026–2027

Электронный ежедневник в духе Hobonichi с октября 2026 по декабрь 2027. Одна HTML-страница, без сборки.

- **Месяцы** — календарь, где каждый день можно украсить фото в виде почтовой марки с перфорацией.
- **Недели** — слева дни с записями и пунктами «Туду» (отмеченное зачёркивается неровной линией), справа страница в клетку для рисования пером или список дел на неделю.
- **Обложка** — паттерн с цветочками, однотонный цвет месяца, горошек, клетка, полоска или своя картинка.
- Рукописный шрифт Yes siree bob, свайпы, рассчитан на телефон; на iPad в горизонтали — разворот из двух страниц.

## Запуск

Откройте `index.html` в браузере. Без облачного хранилища Claude данные сохраняются в `localStorage` этого браузера.

## Сторонние материалы

Шрифт «Yes siree bob» встроен в `index.html`. Его лицензия на странице источника не указана — перед публичным распространением проверьте условия у автора.
