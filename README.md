# Фотоквиток

Карманный принтер воспоминаний: фотодневник, где каждый день становится маленьким бумажным квитком. Мобильная веб-версия, работает в Safari на iPhone без регистрации и сервера.

**Как проходит день**

1. «Сегодня»: из щели красного принтера торчит край бумаги с датой. «Добавить фото» — от одного до трёх снимков.
2. Фото сразу раскладываются на квитке: одно во всю ширину, два рядом, три — крупное сверху и два под ним. Нажмите на фото, чтобы сделать его обложкой, заменить или убрать. Ниже — одна короткая подпись, её можно не писать.
3. «К печати» — принтер втягивает лист. Потяните край бумаги вниз: квиток идёт за пальцем, а когда вытянут достаточно, принтер допечатывает сам и ставит синий штамп с днём недели. Отпустили рано — лента вернётся. Или просто нажмите «Напечатать».
4. «Мой рулон»: все квитки месяца одной лентой с перфорацией. Квиток или весь месяц можно сохранить картинкой PNG — только бумага с фото, датами и подписями.

Квиток за сегодня можно открыть снова и поправить подпись или фото, номер сохранится.

## Запуск

Это обычные статические файлы, сборка не нужна.

- **Локально:** `python3 -m http.server` в папке проекта, затем откройте `http://localhost:8000`. С телефона в той же Wi-Fi сети — `http://<адрес-компьютера>:8000`.
- **GitHub Pages:** Settings → Pages → Deploy from a branch → ветка с Фотоквитком, папка `/ (root)`.
- **На iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран Домой», и приложение откроется без панелей браузера.

## Данные

Всё хранится только на этом устройстве, в IndexedDB браузера (`fotokvitok`): квитки по датам, фото (уменьшаются до 1600 px по длинной стороне, JPEG) и черновик дня. Если очистить данные сайта в Safari, квитки пропадут — сохраняйте важные картинкой.

## Старый Хобоничи

Прежний дневник лежит в `old/` (`/hobonichi/old/`) и работает как раньше; его записи в `localStorage` не трогаются. В «Моём рулоне» можно перенести фото дней из старого дневника квитками.

## Файлы

- `fonts/` — IBM Plex Mono (кириллица и латиница), лицензия SIL OFL, `fonts/OFL-IBM-Plex-Mono.txt`
- `old/index.html` — Хобоничи 2026–2027
